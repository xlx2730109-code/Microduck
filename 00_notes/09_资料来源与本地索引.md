## 缺口与限制

- B 站 API 本轮返回 `code=-352`，网页访问也有限制。视频目录保留原仓可追溯的前六集地址；搜索结果可见第八集标题，尚未获得其独立 BV 链接。平台视频未下载。
- 微雪文档中的 Adapter A 原理图旧链接返回 404；不以其他型号原理图替代。
- 飞特 Gitee BAM 页面抓取失败，没有把整个厂家 BAM 库计为已下载。适配仓内的现有参数与出处另行保留。
- 部分最初 ZIP/Git 大包传输失败，已用逐文件加 Git blob 校验补齐；这些失败不再意味着仓库缺文件。
- 自然对话是新增集成工作，资料不证明本机能录音、全双工、唤醒、打断或视觉问答。
- 原许可逐目录保留。官方代码、几何与第三方模型/个人中控的许可不同，不为整个资料包统一重新授权。
- 备选 `microduck-community-kit` 的 `firmware/GD32F30x_Firmware_Library` 是外部 Git 子模块，未递归下载。该项不属于当前推荐 STM32 FT6 成品路线；若以后编译该备选固件，需按固定子模块提交补齐厂家库。

## 3. HAT、IMU 与 HUB：购买一套完整配套

### 3.1 HAT 版本比较

| 对象 | 差异 | 购买判断 |
|---|---|---|
| kissqy AMP2.0，2026-10-15 工程 | 总线 AMP2.0 3P，音频 HP1.25 2P；新增 RX 指示相关器件 | **现有飞特套件优先询价的版本** |
| kissqy 原 EH2.5 接口版 | 插座和配套线束不同，原采购成本表对应此版 | 有成套已测件也能评估；不能照搬 AMP2.0 插头 |
| Pollen HAT C1 | 复刻作者有使用记录；原官方设计并非飞特线束专版 | 要核对总线与音频转接 |
| Pollen HAT D1 | 官方列出换用 LSM6DSV16X、RS485 和音频端子变更 | 更新不代表对旧复刻镜像更成熟，须单独核对 |
| fanhao 新版三板 | 公开工程有参考价值，README 仍记为未打样实测 | 不作为成品优先目标的直接下单方案 |

工程依据 [S05][S07][S08]。HAT 内置的头部 IMU 不等同于躯干 IMU；本项目保留独立躯干反馈位置。

推荐版的主要器件为 `TLV320AIC3104IRHBR` 音频 codec、`PAM8406DR` 功放、`AP63205WU-7` 5V 降压与 `LMA2718T421-OA5-2` 板载模拟 MEMS。核对来源为本地 `AMP2.0-BOM.json`；这些是成品识别依据，不是让用户逐颗买元器件。

### 3.2 躯干 IMU 比较

| 方案 | 具体对象 | 软件要求 | 本轮判断 |
|---|---|---|---|
| STM32 总线成品 | STM32G031F8P6＋LSM6DSV16XTR，匹配 RevA/AMP2.0 板，FT6 | V167/control.43 或明确支持 FT6 的 fork/镜像 | **优先**，减少自焊和固件适配 |
| LSM6DSV16X 模块直连 I²C | 3.3V 模块，地址 0x6A/0x6B | 采用支持该模块的 fanhao fork | 备选；模块排针和固定方式也需处理 |
| BNO085/BNO086 模块直连 I²C | 对应模块及正确接线 | 对应 fork；注意融合模式和该版本实机记录 | 不因“九轴/自带融合”就判定更稳定 |
| GD32 社区 IMU 或其他 imu_to_dxl | MCU、寄存器和固件可能不同 | 按该板专用运行时合同核对 | 不把 STM32 FT6 文件刷到其他 MCU |
| MPU6050、ICM42688 等通用模块 | 传感器型号不同 | 驱动、融合、安装与时序需另适配 | 不作为免开发替代品 |

FT6 当前合同为 **飞特协议、1Mbps、ID 200**，固件与主控服务分开升级 [S06]。不能只凭名称 `imu_to_dxl` 或 LED 亮就判定买对。I²C 方案还须注意 D1 板上 LSM6DSV16X 已占 0x6A，外置模块需避让；旧 fork 文档与最新镜像的验证范围应分别阅读 [S08][S09]。

### 3.3 下单描述中必须写清

| 项目 | 要求 |
|---|---|
| HAT | 已焊 PCBA；工程日期、接口版、正反面照片；同批 ZERO 的 5V、总线与录放音测试 |
| IMU | MCU 与传感器完整型号、FT6 文件名、ID/波特率、转动时数据更新证明 |
| HUB/触点板 | 匹配用户现有飞特打印件；电池接触件、固定件和线束范围列明 |

在此类社区 PCBA 上，清楚的工程来源、焊接检查和负载测试比商品名中的“高配”更有判断价值。尚未收到卖家报价或测试材料。

## 4. 相机与 ToF：原厂 IMX219 保持兼容

| 选择 | 优点 | 代价/限制 | 建议 |
|---|---|---|---|
| **Radxa 8M219 原厂模组** | 明确为 IMX219，官方列出 ZERO 3W 兼容与专用排线 | 本机镜像仍需启用相机并验证长期出图 | **首版推荐** |
| 通用 IMX219 板 | 可能便宜或提供不同镜头 | 芯片相同不保证孔位、FPC、触点、镜头高度和调试参数相同 | 有完整尺寸与驱动证据才选 |
| Raspberry Pi Camera Module 3 / IMX708 | 支持自动对焦，传感器规格更新 | 树莓派生态的兼容声明不等于 ZERO 兼容；模组高度变化 | 首轮不替换 |
| USB 摄像头 | 可走 UVC，调试方便 | USB 口、外形、重量和线缆占用增加 | 台架备选，非原面板直接替换 |

原厂明确的 FPC 是 **22P/0.5mm → 15P/1.0mm，同面**，不是“买一条 22Pin 线就行” [S10]。相机与主控都在头部，排线无需跨脖子；默认 150mm 可按头内走线整理，追求短线时先核对折弯和插座位置。

Camera Module 3 的对焦能力与更高模组高度来自树莓派规格书 [S11]；上述不优先换用的结论是兼容性判断，不是画质测评。

ToF 是可选扩展；用户已购 VL53L8CX，先按 BOM B014 核对外形/孔距，暂不重复买。该芯片在归档驱动支持范围，但作者常见长板样品约 33.4mm 长、孔距约 28mm，曾装不进默认脸壳；这些不是本机实测。若确实不匹配，可换 **VL53L5CX 小载板 V2＋盖片、匹配面板孔距**，不为可选传感器改已确认的打印件或拖延首走。不能买成 VL53L0X、VL53L1X 或 VL53L7CX 后期待原程序直接识别。芯片功能看 ST 资料 [S12]，板型与踩坑见复刻采购记录 [S13] 和本机 BOM 所列原文。

**已购电池仍须通过适配验收。** 优先取得：实物长宽厚、称重、连续/峰值放电及保护限流说明，再与打印件配合。换大电池会改变质量和重心，未验证前不承诺更长续航或更稳步态。

“10A 电池”也不代表每个 HUB、触点和小插座都能连续通过 10A。整机供电要结合实际压降、温升和各段接插件核对；台架电源或电池均不以全部舵机同时堵转为正常工况。

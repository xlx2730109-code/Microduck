## 模块用途与连接关系


| 链路         | 对应物料                                              | 负责什么                                                               |
| -------------- | ------------------------------------------------------- | ------------------------------------------------------------------------ |
| 主控与系统   | B015＋B024                                            | ZERO 从系统卡启动，运行策略、相机和云语音客户端；训练在电脑/服务器进行 |
| 整机供电     | B008/B009 → B019 → 配套 HAT/HUB 电源分配            | 电池通过触点取电；配套降压供主控稳定 5V，舵机使用匹配的供电分支        |
| 关节控制     | ZERO → B016 总线接口 → B018/B026 → B001            | 主控下发动作并读取反馈；HAT/HUB 不是另一个训练主机                     |
| 躯干姿态反馈 | B017 → 飞特总线 → B016 → ZERO                      | 躯干 IMU 提供机身姿态/角速度；HAT 的头部 IMU 不能直接顶替              |
| 真实画面     | B020 → B021 → ZERO CSI                              | 摄像头采集画面，视频预览与视觉问答分别联调                             |
| 自然对话     | B023 → HAT 音频 → ZERO 客户端 → Wi-Fi 云端 → B022 | 录音、请求云服务并播放回答，不依赖调试电脑常开                         |
| 可选测距     | B014 → 匹配 I²C 接口 → 主控 ToF 服务               | 多区测距；先解决板型、线序和供电，首走不依赖此模块                     |
| 舵机台架调试 | 电脑 → B006/B007 → 单颗 B001                        | 初始读取、配置与编号；微雪 USB 板不计为已买 HAT                        |

以上是功能关系，不是逐针接线图。实际针序、电源分支、端口及共地方式按最终 PCBA 与线束图核对。

## 主控拟购判断

用户在 P5 框出 **2GB、无 eMMC、带排针**，与 ZERO 3W 运动路线相符；尚无订单，记为拟购。对首版相机和云对话并发目标，优先询价同批已测的 4GB 无 eMMC 已焊排针版，这是内存余量建议，未做本机性能比较；若 2GB 有完整成套验证和更快交付，可保留并用轻量客户端实测。

原厂 SKU 分别为 2GB 的 `RS107-D2E0H1W15` 与 4GB 的 `RS107-D4E0H1W15`，依据 [原厂规格书](https://dl.radxa.com/zero3/docs/hw/3w/radxa_zero_3w_product_brief.pdf)。[py-xiaozhi 文档](https://github.com/huangjunsen0406/py-xiaozhi)推荐至少 4GB，属于客户端配置建议，不是已测 ZERO 性能门槛，也不能保证买 4GB 即完成语音集成。

P5 的选项呈灰色，底部写“补货中，批量100个以上请联系客服”，显示价 ¥888；仅凭截图不能确认可售库存、个人起订量或该配置真实报价。先取得 2GB/4GB 分别的实价、零售库存、交期、PCB/Wi-Fi 实物信息与已测镜像。主图没焊排针也不能代替所选 SKU 的信息，须取得实际发货的已焊排针照片。

可发给卖家核对：

> 我要给飞特版 Microduck 配 Radxa ZERO 3W，无 eMMC、40Pin 排针已焊好。请分别报 2GB 和 4GB 的单块实价、零售库存和发货时间；页面 ¥888 是否对应我框出的配置？请给实际板卡正反面、PCB 丝印和 Wi-Fi 模组照片，并说明与 kissqy R1/control.43 或其他哪套 Microduck 镜像验证过启动、无线和摄像头。不是仅附送未焊排针，也不要换 ZERO 3E 或其他板卡。

## 外部采购建议的复核

结论：可按本表选定的第二张方案继续核对成品配套，**不能照第一张聊天截图整套下单**。截图中的“复制搜索词就不会买错”不是版本兼容证明；BoBoMaker 店名也不是可唯一核对的 PCB/固件型号。若卖家提供另一套完整软硬件，应先取得实际板号、IMU 位置/协议、运行固件和整机测试证据，再作为独立方案比较。


| 第一张截图的说法                              | 本机采用的判断                                                                                  | 处理                                                                                   |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| HAT 自带机身 IMU，所以不用额外躯干 IMU        | 当前官方配置将 HAT 的 BMI088 归为头部 IMU；本机 FT6 躯干反馈另有独立板                          | B016 HAT 与 B017 躯干 IMU 分开列，不能用头部反馈顶替躯干姿态                           |
| 再买一个头部 BMI160，直接插 I²C，不改线/固件 | 当前归档未发现 BMI160 路径；I²C 接口相同不代表驱动、板型、针序相同，BMI160 也不等于 BMI088     | 不继续按该说法购买，已购 B012 按退货或开发备件处理；不计为直接可用头部模块             |
| 只买 2GB，拒绝 4GB/8GB 和一切 eMMC 版         | 2GB 是有效运动基线；相机与云语音并发可以优先考虑同批已测 4GB。eMMC 是存储选项，不等于必然不兼容 | B015 记录用户拟选 2GB 与 4GB 条件建议，不将容量建议变成已购事实；SD 卡路线仍为当前优先 |
| 裸板、不要散热片，保证插上就用                | HAT 直插需要已焊排针；散热取决于头壳空间和实际温度                                              | 核对实物排针、间隙和热表现，不凭一句“裸板”买成缺排针版本，也不提前排除散热           |
| NP-F550 电池仓按 6V 供电                      | 电池端、舵机端与主控端是不同分支；ZERO 官方只支持 5V 输入，电池与降压须看真实铭牌和配套设计     | 不把全机统一接成 6V，不将电池端直接接主控 5V；到货按供电流程验收                       |

| 3W 扬声器即可，其他按通用轴承/螺丝列表补齐    | 录音、功放/阻抗、音频接口与云客户端也要匹配；轴承和打印件已有明确确认                           | 依本机 B 行查缺，不因通用截图追加轴承/螺丝或漏掉麦克风链路                             |

根据用户成品优先、尽快复现的选择，当前推荐 A 的配套成品路线，B 保留参考。两条路线的标定、镜像与服务不交叉安装；首版摄像头与独立云端自然对话见补购清单。

## 采购与到货执行顺序

1. 先处理 B015 主控的库存、实价和镜像批次；最终只确定一个版本，不把拟购写为已付款。
2. 向成品卖家一次询齐 B016–B019 与 B026，逐项列板号、接口、线束和已测固件，优先取得无需自行焊接的整套交付。
3. 核对 B020–B023 的相机/音频与 HAT 包含范围，再补存储和读卡器；首版需要真实画面与自然对话，ToF 可以后装。
4. 到货按 B 行逐项记实数、照片、铭牌和测试结果；螺丝、舵盘、脚垫、线材先扣除已有内容。两款电池和单充优先验收，不重买备选品牌。
5. 准备供电检查与机身承托工具，完成单舵机、装配、标定、架空与首走验收；不将“买齐”登记成“复现通过”。

ST-LINK 只在需要自行烧录 STM32 时增加，成品已刷且验证通过不要求重复购买。额外缓冲电容须先检查已有电源设计，再决定是否需要；轮滑件、独立语音板和其他升级模块不列为首版必买。

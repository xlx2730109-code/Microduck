# 版本差异与避坑

目标：在装配、烧录、训练和部署之间保持同一套硬件与数据契约。

**当前路线更新：按fanhao 20261023c及其Studio执行，见 [主指南](02_分阶段复现指南.md)。** 下表含历史差异，R1/V167只用于辨识旧资料；不能把早期“买不到HAT、必须自己重训”等研究文字当作当前施工指令。

| 层 | 已查到的差异 | 本项目采用的处理 |
|---|---|---|
| 产品身份 | 官方 Microduck、Open Duck Mini、不同国产舵机复刻外形相似，硬件不同 | 以截图 HD-1910 为候选主线；Open Duck 不作为本机直接装配基线 |
| 舵机 | XL330 与 HD-1910 的舵盘配合、总线协议和动力学不同 | 机械选飞特版，软件选飞特后端；官方策略不视为 HD-1910 验收策略 |
| 打印几何 | 官方 MJCF/STL 主要服务仿真，不保证可制造、螺丝配合和线缆空间 | 实物以可编辑飞特 CAD、实物试装为准 |
| CAD | 飞特 v2.2 为 2026-10-20 散热孔/上腿间隙更新；原版 XL330 是另一套 | v2.2 作为对照候选；卖家件版本未确认，不强制整套重打 |
| PDF | 21 页手册仍沿用旧版装配截图，关节命名不完全等同于策略关节名 | 用其观察装配关系；具体配合件看 v2.2；关节映射看运行时合同 |
| 轮滑 | fanhao 3MF 仍有旧式分体轮辋/轮胎，v2.1 另有合体 TPU 轮胎；kissqy 缝合怪用另一种脚与 623ZZ | 首走不装轮滑；以后选定单一机械方案再配件 |
| 材料 | 3MF 的默认 PLA 不能覆盖所有柔性件 | 软嘴、软下巴、轮胎等依实际机械版核对 TPU |
| 模型质量 | 加铝件、换电池/脚垫、外接计算板会改变质量、惯量和接触 | 记录实测质量；能装上不等于现成策略能走 |
| 主控 | Radxa ZERO 3W 不同 PCB/Wi-Fi 修订对引导、DTB 有差异 | 拍明版本后再选系统；不依据“同叫 ZERO 3W”批量套启动修复 |
| 镜像 | kissqy R1 自带 control.40；中控 V167 与 control.43 配套 | 刷卡后先检查实际版本，再按同版文档升级，不能只看镜像文件名 |
| fork | fanhao I²C fork 仍可报与 kissqy 相同版本号，但有不同 IMU/控制代码 | 额外记录仓库、分支、提交、安装清单和镜像哈希 |
| fanhao 镜像 | Release 标记与正文“预发布/真机验收中”表述不同 | 以正文验收边界为准；不因 GitHub 页面非 prerelease 就称其全面验证 |
| IMU MCU | kissqy FT6 用 STM32G031F8P6；其他社区板存在不同 MCU/bootloader | 按 PCB/MCU/原理图/协议版本四项配套，不能互刷 `.bin` |
| IMU 协议 | 同叫 `imu_to_dxl` 不证明输出 Dynamixel 或 FT6 相同寄存器 | 先查总线身份、数据区布局、主控读取代码 |
| I²C IMU | kissqy 原版服务只认总线 IMU ID 200；I²C 需要 fork 或专门适配 | 不将一块 BNO085 直接接上原版服务后宣称完成反馈闭环 |
| IMU 方向 | 头部 IMU 与躯干 IMU 功能不同；模块安装旋转会改变坐标变换 | 逐轴倾斜核验，保存本机安装方向，不复制作者样机四元数 |
| 舵机模式 | 社区特定批次写模式 4；厂家通用/型号页面仍有模式 0 描述，型号专用内存表尚有缺项 | 先读取本机固件与寄存器，不根据其他系列表盲写运行模式 |
| 电压 | 官方型号页列 4–8.4 V，Wiki 摘要写 5–8.4 V；最高值一致 | 本轮不据此给出最低可运行保证；2S 满电上限与负载压降要现场量 |
| 调试板 | 微雪 A 板没有稳压，官方 FAQ 说明最大承载 5 A；不能套 URT-2 供电推断 | 认清实物后，按其原理图/丝印和电源分支核对；不让全部电机电流盲目通过调试板 |
| 接线 | 5264、AMP2.0、EH2.5、PH2.0 的名字与间距不能代替键位/针序 | 断电按实物编号查通断；不按线色、照片左右或“能插进去”判断 |
| 零位 | 编码器 2048、中位校准、URDF `q=0`、HOME、策略默认角是不同概念 | 分别记录，不把 HOME 重新写成电机零位 |
| ID | 官方常用 10–14/20–24/30–34；其他复刻存在 1–15 | 以选定运行时配置为准；模型数组索引不等于总线 ID |
| 卸力 | 停进程/重启服务不保证已发出并确认扭矩关闭 | 支撑机身，使用所选程序明确的卸力流程并确认回读；硬件断电方式事先准备好 |
| 中控演示 | GitHub Pages 的 3D 演示使用模拟数据 | 不作为真机接通、校准、性能或安全证明 |
| 训练版本 | 当前官方默认分支与 V167 训练中控冻结的官方提交不同 | 后续训练优先按所选运行时冻结合同，不把最新训练输出直接塞进旧服务 |
| 策略合同 | 关节顺序、观测维度、归一化、HOME、缩放、频率均须匹配 | 逐模型查 `deployment-contract.json` 等元数据，不能仅凭 `.onnx` 后缀判断兼容 |
| 许可 | 官方代码、几何、第三方自训权重、个人中控采用不同条款 | 各目录保留原许可，不为整个资料包统一贴 MIT/Apache 标签 |

## 原始材料中的限制

1. 装配手册已核对为 21 页，页面图文可读。它没有逐颗螺丝长度、逐根接线或本机标定值，不能单独承担完整施工依据。
2. 原始 CAD BOM 的数量、材料与计价问题见 [零件清单](01_BOM表.md)。保留原表，不把修正建议伪装成作者发布版。
3. fanhao 对 BNO085 的陀螺融合有实机记录，同时明确没有完成严格交错 A/B、存在转向与重启等问题。可用作排障线索，不能外推为我们这台必定稳定。
4. 微雪文档中的 Adapter (A) 原理图链接本轮返回 404，失败也登记在下载清单中。没有把错误 HTML 当作 PDF 留用。
5. B 站公开合集接口本轮返回 `code=-352`。已保存前六集的原仓链接；第三方提到第八集，但本轮未独立取得原作者有效 BV 链接，未编造视频地址。
6. 本轮不对来源里的所有“已验证”宣称做实验背书。下载、解压、哈希、PDF/BOM 核对属于资料完整性检查，不代表机械/电气/策略实机验收。

## ZERO 使用 5 GHz Wi-Fi

使用 2.4 GHz 无线手柄时，ZERO 应连接路由器的 5 GHz 频段，否则可能互相干扰，出现断网与 SSH 超时。依据：kissqy 装机注意事项，作者实机经验。

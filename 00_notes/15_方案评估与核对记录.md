## 七、与官方原版的差异和风险

评估依据：官方 `pollen-robotics/microduck` 的 README，fanhao 固定源码中的 `执行器选型.md`、`HD-1910训练前数据清单.md`、README 实机记录，以及本地 [06 动作清单](06_复现完整性与动作清单.md)。标“推测”的为本评估的判断，尚无实测。

### A. 硬件差异

| 项目 | 官方原版 | fanhao 飞特版 | 影响 |
|---|---|---|---|
| 舵机 | Dynamixel XL330 ×15，18 g，堵转 0.52 N·m（5V）；官方实际以 6.6–8.2 V 超压使用 | HD-1910-C001 ×15，21 g，规格书堵转约 1.47 N·m（7.4V），额定 4–8.4 V | 力矩约 2.5 倍，余量更大；满电 8.4 V 正处额定上限，无余量（推测：长期满电使用寿命需观察） |
| 整机质量 | 约 737 g（仿真值），官方 README 写约 800 g | 作者实测带电池约 806 g | 差异小；训练值 820 g，与实机差 1.7%（作者记录） |
| 躯干 IMU | 官方 `imu_to_dxl` 板，未开源 | fanhao 逆向重绘的同名板，或 kissqy 的 FT6 板；新版三块板未打样 | 这是全机最不确定的零件，板与固件版本必须与镜像配套 |
| 供电 | 电池直连舵机，板上一颗降压给主控 | 同一思路，NP-F550 直连；无电池保护板 | 走路时整机掉电已被作者遇到，靠限制转矩缓解 |
| 材料 | 官方成品件 | PLA 打印，部分件可换铝合金 | 刚度与公差依赖打印质量，需自己控制 |

### B. 软件与性能差异

| 项目 | 官方原版 | fanhao 飞特版 | 影响 |
|---|---|---|---|
| 舵机动力学模型 | 官方自己辨识 | 借用陆吾 1910 M6 参数，作者注明“不是自行辨识”；飞特官方另有一份参数，两者差异大且均未在真机比较 | 仿真与真机有差距，步态质量可能不及官方（推测）；首走够用，精细步态受限 |
| 质量与惯量 | 官方 CAD 导出 | 仍用 XL330 版仿真值，作者称后续需按实机校正 | 同上 |
| 实机表现 | 官方视频：行走、起身、坐、踢球、滚动 | 作者记录：已稳定行走；转向偏弱；偶发整机重启；脚抬得不够高会蹭地；已用 D=0、转矩限制 700 缓解 | 首走可行，动作流畅度与官方有差距（来自作者记录，非本机测试） |
| 起身与其他动作 | 官方有倒地起身、坐站、踢球 | 10 个模型都在，本机均未验证；`deployment_verified=false` | 不得假设一次摔倒能自己站起来 |
| 保护行为 | 官方有更新回滚与健康检查 | 摔倒不自动卸力，低电压不自动关机 | 须人在旁边，看到警告立即处理 |
| 整套能力 | 官方有手机应用、蓝牙、OTA 更新、目标检测、NFC、里程计等 | 镜像只含运动、Studio、相机与 ToF 页面；底图来自社区镜像转换而成 | 不具备官方的后几项能力；运行端是 fork，不要执行官方更新，会覆盖 fork（推测，更新机制未在本机验证） |

### C. 结论

1. 机械和电气方案合理：飞特舵机力矩更大、价格约为一半，是 fanhao 项目的核心取舍；其代价是软件链路里有三处借用或沿用的参数（舵机参数、质量惯量、IMU 板），因此实机表现比官方更依赖现场调试。
2. 按 fanhao 复现能做到：行走、手柄遥控、网页标定与诊断、相机与 ToF 页面。做不到或未验证：官方全套应用能力、倒地自动起身的可靠性、轮滑。
3. 最大的三个风险依次是：躯干 IMU 板的版本与固件；走路时的供电压降；ZERO 3W 批次与镜像的兼容。

## 十二、codex 核查吸收记录（2026-10-25）

核查原件存于 `90_sources/references/codex_意见_20261025/`。其结论与本仓库已有记录一致的部分见根 README K101；以下是此前未写入文档的要点。

| 编号 | 要点 | 处理 |
|---|---|---|
| C1 | IMU 板 ID 200 在总线读序中的位置有两种说法：fanhao 旧 IMU 固件实测排在舵机之后，kissqy FT6 要求排在 Sync Read 列表首位，且不要移植其他排队逻辑 | 拿到 IMU 板后，先问清板型与固件，再选对应运行端，不混用，对应 README T38 |

| C4 | 系统辨识当前不是本机结果：公开参数没有附原始数据、电压和固件；台架脚本仍指向原版舵机；若自测，先做能读回和卸力的单关节台架，拆拟合集与留出集，最后用整机闭环验证 | 列入阶段二环节 4，对应 T39 |
| C5 | 训练台打包的成果包没有部署合同文件；机器人导入要求同次导出的策略、`manifest.json`、`deployment-contract.json`，并通过 `robotd validate-policy`；成果包含 PT 和视频时可能超过导入的 64 MiB 上限 | 列入阶段二环节 7，对应 T39 |
| C6 | 自训练前提：PT 与 ONNX 数值对照、独立 HD1910 回放、运行端预检，应以一个真实小实验走通后再写成可执行步骤 | 对应 T39 |
| C7 | 称重只得总质量和分块质量，得不到惯量与重心 | 阶段二环节 3 说明 |
| C8 | 两颗 IMU 并存时，头部 HAT 上的 IMU 默认关闭，不与躯干 IMU 融合 | 到货后核对运行配置 |

## 十三、fanhao 与 kissqy 对比（2026-10-26）

依据：codex 交接稿（存于 `90_sources/references/codex_fanhao与kissqy对比_20261026.md`）加本地核对。本地核对三项：10 个成品 ONNX 的 SHA256 全部出现在 kissqy 发布清单中；kissqy 采购总表确实把 HAT ¥119、IMU ¥99 指向淘宝商品 1095121548583；kissqy 装机说明确实要求总电源入口并联 1000 µF 电容。

| 维度 | fanhao | kissqy | 本机取舍 |
|---|---|---|---|
| 关系 | 在 kissqy 运行程序与模型基础上增加 I²C 与总线 IMU 兼容、板端 Studio、做卡与标定流程，并结合机械行者的机械资料 | 提供飞特运行适配、配套 FT6 IMU 板、机器人与训练中控、自训模型 | 两者同源，不是两只完全不同的鸭子 |
| 成品电路板 | 自绘新版 IMU、HUB、触点板，作者注明未打样实测 | 作者店有 HAT 与 IMU 成品，AMP2.0 版 | 买 kissqy 成品 |
| 机械 | SolidWorks 可编辑文件、STEP、装配 PDF、视频 | 以 STL 与 3MF 为主 | 机械沿用 fanhao，已购打印件不换 |
| 手机操作 | 板端网页 8000 | 中控通常在电脑上运行 | 首走用 fanhao 镜像 |
| 训练 | 平地与地形行走等入口，有 GPU 短训与导出记录 | 14 类动作、35 种配方，远端队列，合同检查更完整 | 阶段二优先研究 kissqy 训练工具 |
| 现成策略 | 10 个模型与 kissqy 发布清单一致 | 同 | 步态基础相同，实物差异来自标定、IMU、供电 |
| 许可 | 镜像含模型，保留限制 | 原创部分仅限个人非商业，公司或组织用途须事先书面许可 | 若用于单位报销或科研，须向作者说明并取得授权 |

结论：不存在谁复刻得更好的定论，两者没有同条件实测数据。fanhao 强在机械与首次上手，kissqy 强在配套电路板与训练工具，本机两者结合。

采购要点：
1. 淘宝页的规格是 HAT 与 IMU TO DXL 两项，当前高亮为 HAT，¥119；IMU 按作者采购表为 ¥99，须切换规格核对；合计约 ¥218，不是套装 ¥119。
2. 主图的扬声器与整机是展示，不含在单板里。
3. 向卖家确认：板版本；IMU 是否已刷 `FT6_SYNC15_UART_IRQ_v1`，ID 200，1 Mbps；HAT 40 Pin 排母是否已焊及堆叠高度；麦克风是否附带；喇叭口为 HP1.25 2P，现有杜邦扬声器需转接；1000 µF 电容是否含；与 20261023c 镜像是否实测过。
4. 本机其他件的对应关系见交接稿第 2 节。

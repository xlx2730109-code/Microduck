### C. 建议执行顺序

| 路线 | 顺序 | 阶段终点 |
|---|---|---|
| 最快复刻现成能力 | 冻结电控组合 → 单舵机编号 → 分组件装配与供电验收 → 写卡 → 标定 → 急停与站立 → 低速首走 → 单独验收恢复 → 备份恢复 | 本机可重复完成已记录的动作 |
| 自主训练与改步态 | 冻结物理模型与测量 → 环境短测 → HD1910基线 → 独立评估 → 导出与数值对照 → 补齐部署合同 → 运行端预检 → 真机分级验收 | 训练成果到真机结果有完整可追溯记录 |

自训练不应成为首次使用现成模型行走的前置条件。若需要自己从零训练倒地恢复，再单列HD1910恢复任务适配与验证。
